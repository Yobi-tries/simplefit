# 🚀 GUIDE RAPIDE - Installation en 5 minutes

## 📦 Fichiers à uploader sur GitHub

Tous les fichiers sont prêts ! Tu dois uploader ces 7 fichiers :

1. ✅ `index.html` - Page principale
2. ✅ `app.js` - Code de l'application
3. ✅ `manifest.json` - Configuration PWA
4. ✅ `sw.js` - Service Worker (mode offline)
5. ✅ `icon-192.png` - Icône 192x192
6. ✅ `icon-512.png` - Icône 512x512
7. ✅ `.gitignore` - Configuration Git (optionnel)

## 🎯 Étapes rapides

### 1️⃣ Créer compte GitHub (2 min)
- Va sur https://github.com
- Clique "Sign up"
- Valide ton email

### 2️⃣ Créer repository (1 min)
- Clique le **+** en haut à droite → "New repository"
- Nom : `fitness-tracker`
- ✅ Coche "Public"
- Clique "Create repository"

### 3️⃣ Upload fichiers (1 min)
- Clique "uploading an existing file"
- Glisse-dépose les 7 fichiers ci-dessus
- Clique "Commit changes"

### 4️⃣ Activer GitHub Pages (1 min)
- Va dans **Settings** (onglet)
- Menu gauche → **Pages**
- Source → sélectionne **"main"**
- Clique **Save**
- Attends 1-2 minutes

### 5️⃣ Installer sur téléphone (30 sec)
**Ton URL sera : `https://TON-USERNAME.github.io/fitness-tracker/`**

#### iPhone (Safari) :
1. Ouvre l'URL dans Safari
2. Icône Partager → "Sur l'écran d'accueil"
3. "Ajouter"

#### Android (Chrome) :
1. Ouvre l'URL dans Chrome
2. Popup → "Installer"

## ✨ C'est tout !

L'app est installée sur ton écran d'accueil et fonctionne 100% offline !
