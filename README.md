# 💪 Mon Fitness Tracker - PWA

Application de suivi fitness complète fonctionnant 100% offline.

## 🚀 Installation sur GitHub Pages

### Étape 1 : Créer un compte GitHub
1. Va sur [github.com](https://github.com)
2. Clique sur "Sign up" (gratuit)
3. Valide ton email

### Étape 2 : Créer un nouveau repository
1. Clique sur le **+** en haut à droite → "New repository"
2. Nom du repository : `fitness-tracker` (ou ce que tu veux)
3. **Important** : Coche "Public"
4. Clique "Create repository"

### Étape 3 : Upload les fichiers
1. Dans ton repository, clique sur "uploading an existing file"
2. **Glisse-dépose TOUS les fichiers** de ce dossier :
   - `index.html`
   - `app.js`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
3. Clique "Commit changes"

### Étape 4 : Activer GitHub Pages
1. Va dans **Settings** (onglet en haut)
2. Dans le menu de gauche, clique sur **Pages**
3. Sous "Source", sélectionne **"main"** branch
4. Clique **Save**
5. Attends 1-2 minutes

### Étape 5 : Accéder à ton app
1. L'URL sera : `https://TON-USERNAME.github.io/fitness-tracker/`
2. Ouvre cette URL sur ton téléphone

### Étape 6 : Installer sur téléphone

#### Sur iPhone (Safari) :
1. Ouvre l'URL dans Safari
2. Clique sur l'icône **Partager** (carré avec flèche)
3. Scroll et clique **"Sur l'écran d'accueil"**
4. Clique **"Ajouter"**
5. ✅ L'icône apparaît sur ton écran d'accueil !

#### Sur Android (Chrome) :
1. Ouvre l'URL dans Chrome
2. Un popup "Ajouter à l'écran d'accueil" apparaît
3. Clique **"Installer"** ou **"Ajouter"**
4. ✅ L'icône apparaît sur ton écran d'accueil !

## 🎯 Après l'installation

- L'app fonctionne **100% offline**
- Toutes tes données sont sauvegardées **localement** sur ton téléphone
- Aucune donnée n'est envoyée à des serveurs externes
- Tu peux même désactiver internet et ça marche !

## 🔧 Mettre à jour l'app

Si tu veux modifier quelque chose :
1. Modifie les fichiers sur ton ordinateur
2. Va sur GitHub → ton repository
3. Clique sur le fichier à modifier
4. Clique sur l'icône crayon (Edit)
5. Fais tes modifications
6. Clique "Commit changes"
7. Sur ton téléphone, rafraîchis l'app (swipe down)

## ⚠️ Important

- Les données sont stockées dans le **navigateur de ton téléphone**
- Si tu supprimes l'app ou vides le cache → données perdues
- **Fais des exports réguliers** (bouton "📤 Exporter" dans l'app)

## 🆘 Problèmes ?

**L'app ne s'installe pas ?**
- Vérifie que tu utilises Safari (iPhone) ou Chrome (Android)
- Assure-toi que l'URL commence par `https://`

**Les données disparaissent ?**
- Ne vide pas le cache de ton navigateur
- Fais des exports réguliers

**L'app ne se met pas à jour ?**
- Ferme complètement l'app
- Supprime-la de l'écran d'accueil
- Réinstalle-la depuis l'URL
